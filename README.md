# LH Plan Lab

LH 공공임대주택 법규검토와 개략 건축규모 산정을 한 흐름으로 연결한 Next.js 애플리케이션입니다.

## 실행

Node.js 20.9 이상이 필요합니다.

- Windows: `start-windows.bat` 실행
- macOS/Linux: 터미널에서 `bash start-macos-linux.sh` 실행

또는 다음 명령을 직접 실행합니다.

```bash
NPM_CONFIG_CACHE=/tmp/jaehyun-npm npm ci --no-audit --no-fund
npm run dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

## 구현 범위

- 사업·주소·대지·법규 계획값 입력 및 실시간 재계산
- 공동주택 46㎡/75%와 오피스텔 25㎡/45%의 4개 주차 대안
- 건폐율·용적률·높이·부대시설·주차를 반영한 독립 계산 엔진
- 법적 확정값, 사용자 입력값, 확인 필요값의 상태 분리
- 원 법정·LH 요구·0.3대 조건부·미승인 대체·최종 주차대수를 분리한 계산
- 법규·LH 적합성 미확인 대안의 자동추천 차단
- 프로젝트/버전 브라우저 저장, JSON 불러오기·실제 XLSX·인쇄/PDF 출력
- VWorld 주소 API 서버 연동 및 키 미설정 시 실패 안전 응답
- `가능동 75-1`, `가능동 72-5` 축약 지번 입력 시 업로드 공식문서 기준 대상지 정보 자동입력
- 일반 `동·읍·면·리 + 지번` 입력 시 VWorld 행정구역 검색으로 전체 지번주소 자동보정
- 전국 신규 주소 조회 시 좌표·지적도 개략면적·용도지역·용도지구·지구단위계획과 계획 상한 자동반영
- 국가법령정보 API 검색 결과를 도시계획·건축·주택·소방 검토카드에 자동 연결
- 공식 API 누락 시 Brave Search 서버 검색으로 공식기관 원문후보 수집 및 6시간 캐시
- 복수 필지별 면적·용도지역 조사와 혼합 용도지역 자동확정 차단
- PDF·HWPX·DOCX·XLSX·TXT 본문 및 법규 수치후보 서버 추출
- 실제 XLSX 건축개요·대안비교·산식·법규근거 출력과 JSON 프로젝트 불러오기
- 업로드 문서 본문 추출과 법규 수치후보 구조화(검증 전 계산 미적용)

## 외부 연동

`.env.example`을 `.env.local`로 복사한 뒤 주소·토지이용 조회용 `VWORLD_API_KEY`, 국가법령·자치법규 조회용 `LAW_OPEN_API_OC`, 공식 웹 후속검색용 `BRAVE_SEARCH_API_KEY`를 설정합니다. 키는 Next.js 서버에서만 읽으며 브라우저 저장소, 프로젝트 내보내기 파일 및 Git 저장소에는 저장하지 않습니다. 화면 입력칸은 로컬 진단을 위한 현재 화면 임시값이며 새로고침 시 제거됩니다.

공식 웹 검색 결과는 원문 후보이며, 검색 결과만으로 적용판정을 확정하지 않습니다. 업로드한 PDF·HWPX·DOCX·XLSX·TXT는 본문과 수치후보를 추출하지만 조항·별표·대상필지 적용관계가 검증되기 전에는 계산값으로 승격하지 않습니다. 스캔 PDF OCR, 구형 HWP 바이너리, 원격 첨부파일 자동다운로드는 별도 연동이 필요합니다.
