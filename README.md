# LH Plan Lab

대상지 주소로 관련 법규·지침을 조사해 법규검토표를 만들고, 검토된 법규로 개략 건축규모와 건축개요를 산정하는 Next.js 애플리케이션입니다. 수지분석·공사비 기능은 포함하지 않습니다.

## 실행

Node.js 20.9 이상이 필요합니다.

- Windows: `start-windows.bat` 실행
- macOS/Linux: 터미널에서 `bash start-macos-linux.sh` 실행

또는 다음 명령을 직접 실행합니다.

```bash
NPM_CONFIG_CACHE=/tmp/jaehyun-npm npm ci --no-audit --no-fund
npm run dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

## 사용 흐름

**대상지 입력 → 법규·지침 자동 조사 → 법규검토표 → 규모검토 → 건축개요표**

| 화면 | 내용 |
|---|---|
| ① 프로젝트 | 프로젝트 목록(검토일·법규/규모 완료 상태), 새 검토, 복제·삭제, JSON 불러오기 |
| ② 법규검토 | 실무 법규검토표 양식(구분·내용·관련 법령·비고). 행마다 근거 원문·조항·시행일, 상태(원문 확인 / 검토자 입력 / 후보·조건부 / 근거 누락) |
| ③ 규모검토 | 법규 연동값 → 대안별(공동주택·도시형생활주택·오피스텔, 기본·완화 용적률, 자주식·기계식, 타입 구성, 기준층 호수) 건축개요 비교 |
| ④ 결과 출력 | 엑셀 법규검토표, 엑셀 건축개요표, PDF 검토보고서(근거 법령 발췌 형광펜 부록), JSON 백업 |

## 법규 수치의 확정 원칙

- 법규검토표 행의 연동 수치는 **원문 확인** 또는 **검토자 입력** 상태일 때만 계산에 사용합니다. 후보·근거 누락 행은 표에는 보이지만 계산에서 제외됩니다.
- 우선순위: 검토자 수정 > 검증 근거 라이브러리(`lib/review/library.ts`, 획지 > 지자체) > 국가법령정보 API 조례 조문 자동추출 > 국가법령 일반기준(후보).
- 지구단위계획구역이 검출되면 **획지번호를 입력하기 전까지** 조례 일반값과 용도·높이 행을 후보로 묶습니다. 구역 포함만으로 획지 기준을 적용하지 않습니다.
- 지자체 기계식 허용과 LH 기계식 인수는 별도 행·별도 판정입니다. 두 상한 중 엄격한 값을 적용합니다.
- 근거가 없는 행은 "원문 조문 자동 탐색"(`/api/rule-lookup`)으로 관할 조례·법령 본문을 검색해 조문을 근거로 첨부할 수 있습니다.
- 재조회 시 검토자가 수정·추가한 행은 유지됩니다.

## 코드 구조

- `lib/review/` — 법규검토표 모델(`types.ts`), 행 생성(`build-rows.ts`), 검증 근거 라이브러리(`library.ts`), 국가법령 기준(`national.ts`), 계산 연동(`params.ts`)
- `lib/massing/engine.ts` — 개략 규모 산정 및 건축개요표
- `lib/project/store.ts` — 프로젝트 저장(localStorage)·v1 데이터 자동 이전(원본 키 보존)
- `lib/server/` — VWorld·국가법령정보·LH 청약플러스·문서 분석 서버 모듈
- `app/components/` — 4개 화면

## 외부 연동

`.env.example`을 `.env.local`로 복사한 뒤 주소·토지이용 조회용 `VWORLD_API_KEY`, 국가법령·자치법규 조회용 `LAW_OPEN_API_OC`, 공식 웹 후속검색용 `BRAVE_SEARCH_API_KEY`를 설정합니다. 키는 Next.js 서버에서만 읽으며 브라우저 저장소, 프로젝트 내보내기 파일 및 Git 저장소에는 저장하지 않습니다. 화면 입력칸은 로컬 진단을 위한 현재 화면 임시값이며 새로고침 시 제거됩니다.

공식 웹 검색 결과는 원문 후보이며, 검색 결과만으로 적용판정을 확정하지 않습니다. 업로드한 PDF·HWPX·DOCX·XLSX·TXT는 본문과 수치후보를 추출하지만 조항·별표·대상필지 적용관계가 검증되기 전에는 계산값으로 승격하지 않습니다. 스캔 PDF OCR, 구형 HWP 바이너리, 원격 첨부파일 자동다운로드는 별도 연동이 필요합니다.
