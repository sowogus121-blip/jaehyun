# LH Plan Lab

LH 공공임대주택 법규검토와 개략 건축규모 산정을 한 흐름으로 연결한 Next.js 애플리케이션입니다.

## 실행

Node.js 20.9 이상이 필요합니다.

- Windows: `start-windows.bat` 실행
- macOS/Linux: 터미널에서 `bash start-macos-linux.sh` 실행

또는 다음 명령을 직접 실행합니다.

```bash
NPM_CONFIG_CACHE=/tmp/jaehyun-npm npm ci --no-audit --no-fund
npm run dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

## 구현 범위

- 사업·주소·대지·법규 계획값 입력 및 실시간 재계산
- 공동주택 46㎡/75%와 오피스텔 25㎡/45%의 4개 주차 대안
- 건폐율·용적률·높이·부대시설·주차를 반영한 독립 계산 엔진
- 법적 확정값, 사용자 입력값, 확인 필요값의 상태 분리
- 조건부 0.3대 특례 및 기계식주차 불가 시 안전한 대체 계산
- 프로젝트/버전 브라우저 저장, JSON·Excel용 CSV·인쇄/PDF 출력
- VWorld 주소 API 서버 연동 및 키 미설정 시 실패 안전 응답
- `가능동 75-1`, `가능동 72-5` 축약 지번 입력 시 업로드 공식문서 기준 대상지 정보 자동입력
- 일반 `동·읍·면·리 + 지번` 입력 시 VWorld 행정구역 검색으로 전체 지번주소 자동보정
- 전국 신규 주소 조회 시 좌표·지적도 개략면적·용도지역·용도지구·지구단위계획과 계획 상한 자동반영
- 국가법령정보 API 검색 결과를 도시계획·건축·주택·소방 검토카드에 자동 연결
- 문서 업로드 메타데이터 등록과 외부 분석 연동 필요 상태 표시

## 외부 연동

주소·용도지역 자동조회에는 `VWORLD_API_KEY`, 현행 국가법령 원문조회에는 `LAW_OPEN_API_OC`가 필요합니다. 대상지 입력 화면에 입력한 값은 해당 브라우저에만 보관되어 다시 실행해도 유지되며, 서버나 프로젝트 내보내기 파일에는 포함되지 않습니다. 입력칸을 비우면 저장값도 삭제됩니다. `.env.local` 환경변수로 설정할 수도 있으며, 키가 없어도 수동 입력과 계산 기능은 동작합니다.

지자체 조례, 지구단위계획, LH 최신 공고 및 PDF 본문은 공식 원문을 별도로 확보해야 합니다. 원문을 확보하지 못한 항목은 화면에서 `자료 미확보` 또는 `검토 필요`로 유지합니다.
