# 수도권 LH 후보지 주차·매입 호수·지구단위계획 조건부 자동검토 — 2026-11-01

## 구현 목적과 검증 레벨
- 원문을 찾은 것(official source retrieved)과, 대상지의 해당 규정 적용을 확인한 것(parcel verified), LH 인수를 승인한 것(approved)은 서로 다르다.
- 기존 실제 조회 12곳 + 합필 5가지 사례를 바탕으로 **의정부·파주 주차장조례 기계식 규정**과 **4개 LH 지역본부 최소매입 세대수**를 *먼저 더 엄격하게 거르는 조건*으로 구현했다.
- **법정 주차대수의 용도별 별표 세부계수**는 원문 별표 행별 정밀 추출/지구단위 제외·주차장 설치제한 지역 중첩 확인이 필요하므로 자동 입력하지 않음. 잘못된 0.5·1.0대 숫자를 세대수 산정에 붙이지 않음.
- VWorld 지번 좌표·PNU 및 단일용도지역, 관할 주차장조례 원문 조회 확인, 단일 필지 조건을 만족한 경우에만 시별 **기계식 설치에 관한 부정적 제한**을 계산에 반영. 이는 기계식 인허가 승인 근거가 아님.

### 계산 엔진 연결 방식
- 최종 적용 가능한 기계식주차 비율 = `min(사용자 가정%, LH 공식 공고 인수 최대%, 해당 지자체 조례 최대%)`.
- 의정부 제2·3종 일반주거에서 공동주택 기계식 A-2 = **검토 불가**. 청년 오피스텔 B-2도 위 1,000㎡/5층+20%+최소20대 요건을 확인해야 하며 20대 미만 계획은 **기계식 0대**, 필요한 자주식 대수로 재산정.
- 0.3대는 청년형 전용30㎡ 미만, 입지·공공주택사업자 약정·LH 인수·허가권자 인정이 모두 충족돼야 적용할 수 있다. **LH 기계식 50% 허용 = 시 조례 20/30% 초과 승인 아님.**
- 조례 상한은 해당시 현행 주차장조례 원문에서 교차확인되는 **도면 위치 및 단일필지**에만 적용; 같은 시 이름만 입력했다고 주소가 없는 가상 필지에 자동 적용하지 않는다.
