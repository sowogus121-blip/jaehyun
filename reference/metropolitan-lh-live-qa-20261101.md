# 수도권 LH 신축매입약정 후보지 실운영 API 검증 — 2026-11-01

## 검증 범위와 판정 의미

- 실제 운영 `https://lh-plan-lab.vercel.app/api/site-review`에 **수도권 12개 지번 주소**를 `businessMode=purchase` + 청년/신혼형으로 POST.
- 추가로 **합필 5개 시나리오**를 POST. 모두 HTTP 200과 JSON 본문 수신. 이는 **서버 기능/주소·법규원문 조회 결과**, 해당 현장들이 진짜 LH 매입약정 후보지로 선정·적합하다는 의미가 아니다.
- 상세 법규 적용 단계 결과 `reviewStage=source-discovery`, `applicationAssessmentComplete=false`. 일부 LH PDF 웹 수집 문서가 `failed`/ `link-only`이고, 모든 지단·건축법·임대주차 수치를 최종 법정값으로 검증한 것은 아니다.
- **5개 추가 검증용 주소(비산동 1101·고색동 104·부평동 123-1·제기동 123-1·신길동 123-1)**는 지역별 시스템 회귀 확인을 위한 임의 지번. 실제 LH 매입 추진·권원·토지거래 현황과 관련이 없다.

## 실제 발견된 오류 및 수정

1. **관할 조례 우선 표시:** Paju 준주거 `70/500%`은 시행령의 일반 상한이지 현행 관할 조례값이 아니다. 원문 자치법규 `§32·§33`에서 건폐율/용적률을 모두 정확히 파싱한 경우 **60/300% (조례 일반값)**를 API의 `planningStandards` 우선 참고값으로 변경. **지구단위계획·산업단지 세부 허용용도는 여전히 미확정**.
2. **경기남부 LH 공고 누락:** 안양·수원 등에서 과거/종료 공고가 공식 LH 게시판 최신 조회에서 빠지면 `lhNotice=null`이었다. 2026 경기도 관할별 원문 PDF/ZIP 보관본으로 **접수 종료·참고용** 안전 폴백. 규칙값 자동 승인 금지.
3. **C1 합필 오판:** C1 블록 사용자 지도 확인은 초평동 **630-1 단일 지번**에만 적용. 630-2 등 추가 필지 합필은 모든 필지의 C1 허용용도를 확인하기 전 주거불가 일괄 확정하지 않으며, 인허가 도면/필지별 용적률 확인을 요청하는 조건부 경고로 대체.
4. **합필 용도지역 표기 중복:** 동일한 `제2종일반주거지역`이 VWorld+기존 프리셋 소스마다 중복 출력되던 문제를 카테고리·용도명 기준으로 정규화. **서로 다른 실제 용도지역은 유지**하여 혼합 지역 인허가 제한은 보존.
5. **회귀테스트:** 2026 LH 지역본부 경계·접수종료 폴백·정확한 Paju 조례 수치·C1 단일/합필 분리·부천 인천본부 포함을 자동 테스트.

## 잔여 한계

- 라이브 조회 12곳은 **주소·필지와 법령 원문 후보 수집 단계**. 시행 중 모든 지단 도면, 기계식 주차, 방화, 일조, 실제 사업허용·LH 매입심사 완료를 의미하지 않음.
- 가상 시험지번 3곳에서 원문 지번 불일치로 건축개요 추정 중단. 정확히 존재하는 토지 지번/도로명 주소로 재조회해야 한다.
- **토지의 법정 합필 가능성**은 인접·소유권·법적 제한 검증 전이고, VWorld PNU 조회만으로 허가를 보증하지 않음.
- 0.3대 주차는 전용 30㎡ 미만·지역 공고/유형·입지·매입약정 체결·허가권자 인정 확인 전 자동 적용 불가.
- 실제 새 LH 공고/고시/시행령 업데이트는 향후 버전 동기화 필요; 이번 테스트는 자동 예약 모니터링을 만들지 않았다.
