# 수도권 조례·완화 근거 DB — 1차 수집

- 수집/재대조일: **2026-11-01**
- 코드/데이터: `lib/metro-ordinance-catalog.ts`
- 열람: `/ordinance-library`
- 조회 API: `GET /api/ordinance-library`, `?region=경기`, `?address=경기도%20파주시...`
- 개별 대상지 법규검토/엑셀에 반영: `buildLegalReviewReport`가 주소의 **시 단위 일치**를 기준으로 해당 도시의 법규 근거를 조건부 행으로 추가한다.

## 적용 원칙

1. **법규 원문 확보 ≠ 대상지별 확정 적합**. '조문 대조(clause-checked)'는 공포·개정된 조문내용을 확인했다는 뜻이며, 개별 필지의 지구단위계획·도면·별표·높이·LH 매입조건에 대한 허가를 의미하지 않는다.
2. **재대조(needs-current-recheck)**는 이전 시행본에서 문구를 확인했으나 최신 개정본과 동일한지 미확정인 경우이다. 법률 근거로 자동 연산 불가.
3. **원문 연결(source-indexed)**은 최신 조례 제목·공포일·링크만 확인된 상태이다. 이 상태에서 숫자(용적률·주차·높이)를 만들지 않는다.
4. **자동 완화 적용은 항상 false**. 예를 들어 파주 준주거 용적률 300%와 8년 이상 민간·공공임대 조건부 120% 조항이 있어도, 사업승인·지구단위계획·LH 공고/지자체 해석을 검증하기 전 360%를 승인값으로 쓰지 않는다.
5. 동일 분야에 법규가 여러 개 적용되면 **용도지역→실제 획지 지구단위계획→건축물 허용용도→조례 일반기준 및 별표→특례 조건→해당 연도 LH 매입기준** 순으로 확인한다. 중복 특례는 별도 승인 없이 합산하지 않는다.
6. 법규 시행일이 바뀌거나 폐지·한시 규정 만료시 **별도 데이터 항목으로 버전관리하고 기존 사실을 무단 덮어쓰지 않는다.**

## 재수집 시 점검표

- 해당 시 조례 **최신 시행일과 개정번호를 원문에서 확인**했는가?
- 근거가 조례 본문인지 **별표/시행규칙/지구단위계획**인지 분리했는가?
- `제N조`, `제N항`, 대상 용도지역, 주택유형, 임대기간, 심의·기부채납·접도 요건을 함께 적었는가?
- '**대지별 승인 확인**' 없이 수치를 자동으로 `ProjectInput`에 주입하지 않는가?
- 기존 유사 지번·다른 시청 관할이 **교차 매칭되지 않는지** 테스트했는가?
- 공고 유효기간, 규제지역 지정, 역세권 출입구 직선거리 같은 시기·위치 조건은 확정했는가?

## 다음 미확인 항목

지자체별 건축조례 **대지 안의 공지 별표**, 도시계획조례 별표의 허용·금지용도, LH 지역본부별 매입공고와 기계식주차 인수조건, 임대주택 지구단위계획 특례의 적용 범위를 추가로 수집할 여지가 있다. 이번 1차에 없는 도시는 조회 시 '데이터 없음'으로 남긴다. 전국 일괄 완화나 자동 적합 판정 기능을 추가하지 않았다.
